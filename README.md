## 🌟 Overview

**racun cuan.id** adalah platform all-in-one yang menggabungkan:
1. **🛒 Shopee to Pin Radar & Deck**: Scraper live produk Shopee, deteksi Komisi XTRA hingga 40%+, dan 1-klik generator Pin visual.
2. **⚡ 4-Field Prompt Matrix Studio**: Generator kampanye autopilot niche (*Subjects, Outfits, Locations, Vibes*).
3. **📋 Pin Preview & Curation Queue**: Antrean kurasi visual bergaya Pinterest 2:3 sebelum dispatch massal.
4. **📌 Live Pinterest API v5 Explorer**: Pembaca data live akun Pinterest (Boards, Pins Feed, Analytics performa).
5. **🤖 Pin Autopilot Bot Worker**: Otomatisasi terjadwal dengan perlindungan *humanized delay* & *daily velocity cap*.
6. **📊 Sheets & Excel Cuan Hub**: Auto-logger Google Sheets webhook, download database Excel `.xlsx` & `.csv`.

---

## 🚀 Fitur Utama

- **Live Shopee DOM & JSON-LD Scraper**: Ekstraksi otomatis galeri foto, harga diskon, rating, ulasan, komisi XTRA, dan seller badge.
- **AI Copywriter & SEO Generator**: Didukung Google Gemini AI untuk pembuatan judul catchy, deskripsi SEO persuasif, dan viral hashtags.
- **Pinterest API v5 Direct Publisher & Reader**: Menggunakan endpoint resmi `POST /v5/pins`, `GET /v5/boards`, `GET /v5/pins`, `GET /v5/user_account`.
- **Google Sheets & Webhook Auto-Logger**: Sinkronisasi instan ke spreadsheet Google Sheets & file Excel lokal.
- **Dual Interface**: Web Dashboard di `http://localhost:3000` + Chrome Extension Sidepanel.

## 🛠️ Instalasi & Menjalankan Aplikasi

### 1. Clone & Setup Backend Server
```bash
git clone https://github.com/AarsyDesign/Racun-Cuan-ID.git
cd Racun-Cuan-ID/server
npm install
node server.js
```
Buka web dashboard di: **`http://localhost:3000`**

### 2. Pasang Ekstensi Chrome
1. Buka browser Google Chrome / Brave / Edge $\rightarrow$ ketik `chrome://extensions/`.
2. Aktifkan **Developer Mode** di pojok kanan atas.
3. Klik **Load Unpacked (Muat yang belum dibongkar)**.
4. Pilih folder root `Racun-Cuan-ID`.
5. Ekstensi **racun cuan.id** siap digunakan di sidepanel browser!
