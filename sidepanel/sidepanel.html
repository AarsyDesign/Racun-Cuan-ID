📊 Panduan Cepat Google Sheets Webhook

  1. Buka Google Sheets baru di browser.
  2. Klik menu Extensions (Ekstensi) > Apps Script.
  3. Copy & Paste skrip dari file GOOGLE_SHEETS_GUIDE.md di folder ekstensi.
  4. Klik Deploy (Terapkan) > New Deployment > Pilih Web App.
  5. Pilih Who has access: Anyone (Siapa saja), lalu klik Deploy.
  6. Copy Web App URL dan paste di menu Pengaturan ekstensi ini.
